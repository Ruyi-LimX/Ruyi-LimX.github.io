# Ruyi-LimX.github.io

Personal GitHub Pages site for **Ruyi-LimX**, focused on robotics, vision-language-action systems, embodied AI, and real-robot learning.

## What is included

- Responsive single-page layout
- English / Chinese language switch
- Dark / light themes with saved preference
- Semantic landmarks, keyboard focus styles, and a skip link
- Reduced-motion support
- Open Graph, canonical, and structured-profile metadata
- No analytics, trackers, build system, or third-party JavaScript

The site intentionally does not invent a real name, affiliation, email address, publication record, or project list. Add those sections only when the information is ready to be public.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Main files

- `index.html` — content and page structure
- `styles.css` — visual system and responsive layout
- `script.js` — language, theme, and reveal interactions
- `favicon.svg` — site mark

## GitHub Pages

Publish from the `main` branch and repository root:

1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select **main** and **/(root)**.

The public URL is <https://ruyi-limx.github.io/>.
